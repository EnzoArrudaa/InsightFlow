# InsightFlow

## Sobre o Projeto

O InsightFlow é uma plataforma de análise e visualização de dados desenvolvida para transformar dados empresariais em informações estratégicas.

O sistema utiliza Python para processamento de dados, banco de dados NoSQL para armazenamento e Power BI para criação de dashboards interativos.

## Objetivo

Auxiliar empresas na tomada de decisão através da análise de indicadores, tendências e desempenho operacional.

## Tecnologias Utilizadas

- Python
- MongoDB (NoSQL)
- Power BI
- GitHub

## Pipeline de Dados

1. Coleta de dados
2. Tratamento e limpeza
3. Armazenamento no banco de dados
4. Análise dos dados
5. Visualização em dashboards

## Dashboard

O dashboard apresenta indicadores como:

- Receita Total
- Vendas por Categoria
- Clientes por Região
- Ticket Médio
- Evolução de Vendas
